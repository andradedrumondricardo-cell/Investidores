# Checklist antes de publicar

## Estrutural (uma vez, com advogado de mercado de capitais)
- [ ] Definida a rota de captação: CVM 88, CVM 160 rito automático, veículo regulado ou SCP estritamente privada
- [ ] Parecer escrito sobre o funil (conteúdo → lead → contato)
- [ ] Política de privacidade e termos publicados; encarregado (DPO) indicado
- [ ] Separação documentada entre base de marketing e rede de relacionamento prévio
- [ ] Contrato com agência/influenciadores proibindo copy de investimento e remuneração por captação
- [ ] Revisão de contratos da SCP (sócio ostensivo, prestação de contas, riscos) — mesmo para rota privada

## Por conteúdo
- [ ] Nenhum termo da lista proibida (`02-guia-editorial.md`)
- [ ] Nenhuma taxa, retorno, prazo de investimento ou valor mínimo
- [ ] Nenhuma menção a projeto/SCP da ZeroInvest
- [ ] Seção de riscos presente
- [ ] Fontes citadas
- [ ] Rodapé padrão
- [ ] CTA apenas para newsletter/material educacional
- [ ] Versão arquivada com data
